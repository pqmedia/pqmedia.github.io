Some of the most useful workshop tools do not need to be complicated.

A simple jig or fixture can save time every time you repeat the same job.

## Start With a Real Problem

The best homemade tools usually begin with a problem that happens repeatedly in the workshop.

## Keep It Simple

A tool does not need many parts to be useful.

Good design often means removing unnecessary complexity.
