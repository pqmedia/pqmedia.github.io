This heavy-duty welding clamp was built as a practical tool for everyday fabrication work in the WELD PQ workshop.

## Why We Built It

Commercial clamps work well for many situations, but sometimes a workshop needs a tool designed around a specific type of fabrication work.

The goal was to build something simple, strong and easy to repair.

## Materials

The main structure was made from mild steel.

The design uses common workshop materials that are relatively easy to cut, drill and weld.

## Build Process

The basic process included:

1. Cutting the steel parts.
2. Drilling the required holes.
3. Positioning and tack welding the components.
4. Completing the welds.
5. Grinding and cleaning the finished tool.
6. Testing the clamp in real fabrication work.

## What We Learned

A simple tool can be extremely useful when it solves a real workshop problem.

The most important part of this build was keeping the mechanism strong while still making it easy to use.

## Final Result

The finished clamp is now part of the workshop tool collection and can be used for positioning and holding fabricated steel parts.
